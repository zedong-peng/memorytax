# Paper

`index.html` is the paper, served at [zedongpeng.com/memorytax](https://zedongpeng.com/memorytax/); `arxiv/` holds its static version for arXiv.

One LoCoMo conversation, conv-26, under four memory methods (full context, BM25, Mem0, Zep) and three coding agents (Pi, Codex, Claude Code), each with three models: GPT-4o-mini, and GPT-6 Luna and Claude Opus 5.5 at reasoning effort high.

| File | Role |
| --- | --- |
| `data/conv26_cumulative.json` | every number in Tables 1 and 3 and Figures 1 and 2 (`data/README.md`) |
| `data/conv26_cross.json` | the cells of Table 2 and Figure 3, where the model that reads a Mem0 or Zep store is not the one that wrote it |
| `scripts/cells.py` | complete runs in `results/<method>/<model>/` → `conv26_cumulative.json` |
| `scripts/cross.py` | complete runs in `results/<mem0\|zep>/<writer>-<reader>/` → `conv26_cross.json`, then Table 2 and Figure 3's data |
| `scripts/conv26.py` | `conv26_cumulative.json` → Tables 1 and 3 and the data of Figures 1 and 2 |

The scripts write into `index.html` only between its `<!-- NAME: generated by scripts/... -->` and `<!-- end NAME -->` markers; everything else in it is edited by hand. Run them from `papers/` with the project's Python: `cells.py` after a run, `cross.py` after a writer–reader run, `conv26.py` after the data changes. `MODELS` in `conv26.py` lists the models shown, each with its name and reasoning effort; another model gets its own key and a `--m-<key>` colour in `index.html`. References are numbered by first citation.
