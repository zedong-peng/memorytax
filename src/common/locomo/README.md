# LoCoMo F1

`official.py` is the normalization and F1 of the official evaluator ([snap-research/locomo `3eb6f2c`](https://github.com/snap-research/locomo/blob/3eb6f2c585f5e1699204e3c3bdf7adc5c28cb376/task_eval/evaluation.py)), unchanged; `score.py` computes it per category the official way. `python src/common/locomo/score.py results/<method>/<model>/summary.json` scores the answers a run saved.
